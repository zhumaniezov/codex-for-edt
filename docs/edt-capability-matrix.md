# Матрица возможностей EDT 0.8

Исследована EDT **2026.1.3.25**. Единица учёта — строка capability matrix (семейство операций), а не Java-класс и не каждый метод API. Реестр охватывает **49** конкретных корневых metadata types. Базовое создание, изменение свойств, сохранение и close/open проверены для **48**; `Interface` доступен для чтения, создание отключено. Это не обещание полного CRUD и всех специализированных payload каждого типа.

Матрица: **69 семейств**, **64 PUBLIC_SUPPORTED**, **0 PUBLIC_BUT_EXPERIMENTAL**, **1 INTERNAL_ONLY**, **4 UNKNOWN**. Публичность контракта и наличие готового tool указаны раздельно. В Diagnostics количество public capabilities обозначает именно объявленные инструменты текущего проекта, а не все строки исследования.

## Границы адаптеров и следующие задачи внутри native платформы

- **Tier 1:** все 11 типов имеют native create/read/update/save. Catalog/Document — реквизиты и табличные части; Enum — значения; CommonModule — настройки исполнения и BSL; CommonForm/формы объектов — генерация и дополнение; Subsystem — ссылки content. Role создаётся с native description, но редактирование отдельных прав не объявлено реализованным.
- **Tier 2:** все 11 типов имеют базовый адаптер. Dimensions/resources/attributes регистров задаются по descriptors; InformationRegister проверен с типами и ресурсами. Настройка проводок, движений, перерасчётов, заимствования и runtime-поведения требует отдельных интеграционных сценариев.
- **Tier 3:** базовый native create/update охватывает остальные поддержанные фабрики. HTTPService отдельно проверен с URL template, GET и BSL. XDTO schemas, WSDL, external data source columns, integration payload, картинки/макеты и другие бинарные содержимые не генерируются универсальным setter; для них нужны специализированные публичные адаптеры и tests.
- Контролируемое `removeChild` поддержано только для принадлежащих объекту containment metadata, не формы/макета. Удаление root требует отдельного плана удаления внешних ресурсов и анализа всех ссылок; по наличию `detachTopObject` нельзя обещать полноценное безопасное удаление.
- UI Undo после сохранённого плана, Quick Fix preview/apply, extension borrowing и debug/run остаются явно названными адаптерами. Они не подменяются shell/XML и не объявлены доступными Codex.
