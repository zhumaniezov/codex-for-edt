# Иконки и происхождение

Проверены [метаданные официального OpenVSX extension](https://open-vsx.org/api/openai/chatgpt/latest): версия 26.5908.31748, `SEE LICENSE IN LICENSE.md`, icon `blossom.dark.png`. LICENSE ссылается на [OpenAI Terms of Use](https://openai.com/policies/row-terms-of-use/), а не на свободную лицензию assets. [OpenAI brand guidelines](https://openai.com/brand/) устанавливают ограниченное право использования marks. Однозначное разрешение включить официальный знак в сторонний open-source плагин не подтверждено. Он не скачивался для упаковки и не публикуется.

В проекте используется **оригинальный знак: угловые скобки кода и небольшой четырёхлучевой акцент**. Это не OpenAI blossom и не логотип 1С. SVG нарисованы для этого проекта, не заимствованы из исследованных продуктов. Лицензия оригинальных иконок — MIT, текст находится в `icons/LICENSE.txt`; лицензия не распространяется автоматически на остальной проект и не предоставляет прав на чужие trademarks. Проект не является официальным продуктом OpenAI или 1С.

Для каждой из восьми иконок есть исходный SVG и прямые экспорты 16, 24, 32, 48, 64 px отдельно для светлого и тёмного фона. PNG получены из вектора, без увеличения маленькой растровой картинки. Прозрачный фон. Для extension registry предоставлены `codex.png` и `codex@2x.png`; для toolbar используется `ImageDescriptor.getImageData(zoom)` и `LocalResourceManager` на срок жизни control. На промежуточном неподготовленном масштабе применяется штатный fallback SWT. Небольшая фиксированная палитра относится только к artwork; цвета controls берутся из EDT/SWT. UI выбирает контрастный вариант иконки по фону после изменения темы.

[Публичный ImageDescriptor API](https://help.eclipse.org/latest/topic/org.eclipse.platform.doc.isv/reference/api/org/eclipse/jface/resource/ImageDescriptor.html) описывает DPI-aware descriptor и владение ресурсами. View icon регистрируется в `org.eclipse.ui.views`, поэтому доступна и в Show View. Отдельного image-атрибута feature.xml не используется: для данной feature иконку обеспечивает основной plugin и View.

В 0.5 добавлены собственные геометрические glyphs в `IconButton.java` для header, круглой Send/Stop и вложений. Это векторная отрисовка GC в логических координатах SWT, без новых сторонних assets и raster runtime. Распространяется как исходный код проекта под MIT; View icon и исходные SVG/PNG из 0.4 сохранены.
