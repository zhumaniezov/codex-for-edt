## Что проверяет UI-тест

Тест запускается в настоящем Eclipse workbench с SWT и OSGi extension registry. Он не подменяет View заглушкой.

1. Открывает зарегистрированную View через `IWorkbenchPage.showView`, проверяет заголовок Codex.
2. Проверяет, что пустое и пробельное сообщение не включает Send.
3. Нажимает Send через SWT event и получает локальный ответ.
4. Создаёт уникальный временный workspace-проект и `Module.bsl`.
5. Открывает файл стандартным Eclipse Text Editor, изменяет документ в памяти и выделяет русский текст.
6. Проверяет имя проекта, путь файла и выделение, включая несохранённый текст.
7. Активирует Codex, отправляет сообщение и проверяет, что контекст редактора сохранился.
8. Снимает выделение и проверяет отсутствие старого фрагмента.
9. Переключается на `notes.txt`, затем закрывает редакторы; BSL-контекст не сохраняется ошибочно.
10. Закрывает и снова открывает View.
11. Удаляет только созданный тестовый проект и сохраняет тестовую workspace перед завершением.

Все тестовые файлы находятся внутри проекта Codex. Рабочие конфигурации и информационные базы пользователя не используются.

## Дополнительные проверки и исправления

До появления Maven выполнены компиляция `javac --release 17` на активных библиотеках установленной EDT, упаковка JAR, штатный Eclipse FeaturesAndBundlesPublisher / CategoryPublisher и отдельный SWT smoke harness. Его успешный журнал находится в `.runtime/local-0.1.0.v20260911161152/`. Эта проверка не выдавалась за Maven build.

Также разобраны XML проекта и PowerShell-скрипты, проверено отсутствие в поставляемом Java-коде импортов `.internal`, сетевых клиентов и запуска процессов.

При реальной сборке обнаружены и исправлены:

- неполный runtime classpath Eclipse — добавлены Felix SCR и Aries SPI Fly по официальному примеру;
- отсутствовавшая явная зависимость JFace Text;
- отсутствие EventAdmin в минимальном Tycho UI runtime — добавлены Equinox Event и стартовые уровни;
- неполный набор Hamcrest target — добавлена реализация из официального Eclipse p2;
- запись временных файлов JNA вне тестового каталога — назначен локальный temp;
- ненужная авторегистрация URI-схем при старте тестовой среды — отключена через проектные Eclipse preferences.

## Оставшиеся ограничения и диагностика

Ошибок компиляции, p2 verification и тестов Codex нет.

Tycho выводит предупреждение `0 system scoped dependencies were mapped to maven artifacts ... were skipped`. Оно относится к формированию consumer POM для p2-зависимостей, а не к отсутствующим bundle в runtime. OSGi classpath и тесты разрешены успешно.

В журнале полного EDT runtime наблюдались сообщения подсистем среды:

- не найден `wmic` при поиске web-серверов в Windows 11;
- дублирующееся расширение `org.eclipse.wst.server.ui.ServersView.content.root`;
- отсутствующий working-set filter у Resource Navigator;
- в ранних smoke-запусках — Oomph во время быстрого закрытия EDT; для отдельного запуска отключён его startup.

Эти сообщения не прервали сценарий Codex. Подсистемы web-серверов, Navigator и установщик EDT не исправлялись в рамках плагина. При оценке общего состояния EDT ориентируйтесь на полный журнал; успешный smoke не означает отсутствие всей диагностики самой среды.
